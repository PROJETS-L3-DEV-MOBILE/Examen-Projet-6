## Instructions d'installation

- Créer une base de données MySQL nommée "exam_php"
- Importer le fichier "exam_php.sql" dans la base de données MySQL
- créer un fichier ".env" à la racine du projet contenant :
  DB_HOST=localhost (en local)
  DB_NAME=exam_php (nom de la base de données dans exam_php.sql)
  DB_USER=root (ou nom d'utilisateur mysql)
  DB_PASSWORD= (mot de passe mysql)

- taper la commande "composer install" pour installer les dépendances nécessaires"
- lancer la commande php -S localhost:8000 -t public depuis le répertoire racine du projet
- ouvrir le navigateur avec URL : "localhost:8000"
